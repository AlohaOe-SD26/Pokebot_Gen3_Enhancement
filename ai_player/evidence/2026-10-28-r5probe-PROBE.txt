## How it was measured

- **Driver.** `probe_end_screen.py run`. It runs the AI's play brain in-process, the way `ai_player/gates/play_harness.py`
  `play` does: from `--fresh` (the title screen; the AI plays the intro itself), the cartridge clock pinned to
  `rate_step5.GAME_CLOCK` and the wall clock set to `WALL_CLOCK`, with the personality and starter of `rate_step5.plan_of`.
  It runs on a FROZEN copy of the pre-R5 `ai_player/` (`tree_pre/`, HEAD `714084b0`; `diff -rq` showed it identical to
  the worktree before any edit). The emulator stops on the frame the brain returned: `play`'s loop breaks before
  `run_single_frame`.
- **The harness's own free read** (`game_screen`; it never uses the AI's `nav_free`, per PF-19). FREE means all of:
  - `gMain.callback2 == CB2_Overworld` (raw RAM against the symbol table);
  - `sGlobalScriptContextStatus == 2` (CONTEXT_SHUTDOWN);
  - `sLockFieldControls == 0`;
  - `sFieldMessageBoxMode == 0` and text printer 0 inactive.

  It is read on the end frame and on each of 10 more frames run with NO input. `free_held` means free on all 11.
- **A behavioural check** (`accepts_input`). In a throwaway copy of the end frame's state, the harness taps the direction
  opposite the player's facing and runs 12 frames. The game took input if and only if the facing changed.
- **Seeds.** Development seeds 5301-5304 were written in the worktree's seed ledger BEFORE any run: entry #43, family
  `story`, purpose `development` (`ledger_begin.out`). The entry was closed with its verdict (`ledger_finish.out`). Seed
  5304 was not played.

"""R5 probe: what follows a run's END frame, frame by frame, with NO input (test side).

    py -3.12 film_end.py --root ROOT --state END_STATE --out DIR [--frames N]

Loads the end state a probe run saved (the frame the brain returned), then runs N frames with no input, printing for each
frame the harness's own free read (`probe_end_screen.game_screen`) beside the AI's own eyes (`nav_free`, `busy_reason`,
`fading`, FOR THE RECORD ONLY), and saving a screenshot at a few frames. The frame index 1 is the first frame RUN after the
end frame (a loaded state shows nothing until a frame is drawn)."""

from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE))


def main() -> int:
    try:
        sys.stdout.reconfigure(encoding="utf-8", errors="replace")
    except Exception:
        pass
    parser = argparse.ArgumentParser()
    parser.add_argument("--root", type=Path, required=True)
    parser.add_argument("--state", type=Path, required=True)
    parser.add_argument("--out", type=Path, required=True)
    parser.add_argument("--frames", type=int, default=120)
    args = parser.parse_args()
    from probe_end_screen import boot_at, game_screen

    context = boot_at(args.root.resolve())
    from ai_player.brain.navigator import nav_free
    from ai_player.hands.dialogue import busy_reason
    from ai_player.host.eyes import FrameworkEyes

    emulator = context.emulator
    emulator.load_save_state(args.state.read_bytes())
    eyes = FrameworkEyes()
    args.out.mkdir(parents=True, exist_ok=True)
    shots = {1, 2, 3, 5, 10, 20, 40, 60, 90, 120, 200, 300}
    rows = []
    previous = None
    for frame in range(0, args.frames + 1):
        if frame > 0:
            emulator.run_single_frame()
        read = game_screen()
        seen = eyes.look()
        row = {"after": frame, "game_free": read["free"], "status": read["script_status"], "lock": read["lock"],
               "box": read["box_mode"], "printer0": read["printer0_active"], "fade": read["fade"],
               "ai_nav_free": nav_free(seen), "ai_busy": None if nav_free(seen) else busy_reason(seen),
               "ai_fading": seen.screen.fading, "text": (seen.screen.text or "")[:60] if seen.screen.text else None}
        key = {k: v for k, v in row.items() if k != "after"}
        if key != previous:
            print("FRAME " + json.dumps(row, ensure_ascii=False), flush=True)
            previous = key
        rows.append(row)
        if frame in shots:
            try:
                emulator.get_screenshot().save(args.out / f"after_{frame:03d}.png")
            except Exception as error:  # noqa: BLE001
                print(f"(no screenshot at {frame}: {error})")
    (args.out / "film.json").write_text(json.dumps(rows, ensure_ascii=False), encoding="utf-8")
    print(f"FILM {len(rows)} frames; changes printed above; screenshots at {sorted(shots)} in {args.out}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
