# Documentation history
Versioned snapshots of the upstream documentation, kept for reference.

Convention: before docs are updated for a new upstream sync, the outgoing
versions are copied into `_history/<YYYY-MM-DD>-<upstream-commit>/`
(the date and commit they were accurate FOR). The live docs in the parent
folder always describe the currently mirrored upstream commit (see
`../../UPDATE-LOG.md`).
