I measured it with the probe's synthetic model (100 batches × 400 draws, edge_tests.py). The species set changed in 0 of 40,000 draws at 7 runs per lane, .017% at 5, .1% at 4 and 3.6% at 3. It does not bias tonight's CI.
- **(2) Estimable trainers.** The set is identical for both arms in every draw by construction (`cnt` is shared, :284-288). It never differed between the point estimate and a draw in any configuration. But the point estimate can silently drop trainers and still read CONFIRMATORY (F2).
- **(3) C1, runs with no K* first attempt.** They are EXCLUDED, not zero (:151-155, :225-228), as the DESIGN says; the count with a value is printed.
- **(4) C5 denominator.** Using decided battles (won + lost, with Draw counted as lost) matches the DESIGN. It also matches the POWER baseline, which counted battles with an ended line and dropped wild-only outcomes. Undecided battles are printed.
- **(5) CIs and verdict order.** The percentiles are [2.5, 97.5] and [5, 95] (:331). HIGHER requires lower95 > 0, which already implies NOT LOWER because δ > 0 is enforced (:651). "NOT LOWER, but statistically lower" is lower95 > −δ and upper95 < 0 (:342). C2 LOWER is upper90 < 0; C5 is lower90 > 0 / upper90 < 0; C1 PASS is lower95 > 0. All correct.
- **(6) Reach censoring.** Correct (:217-224): a cut, lost or capped run that never met X is out; a complete run that never met X counts as not reached.
- **(7) Edges.**
  - All wins, or all losses: Δ CI is [0, 0], which reads NOT LOWER, per the rule.
  - Equal bags: C1's CI is [0, 0], so C1 FAILS.

  - Only one trainer estimable: CONFIRMATORY anyway (F2).
- **(8) Seeds.** The grade is reproducible: two CLI runs wrote byte-identical JSON. The seed's Monte Carlo error on lower95 at 10,000 draws has an SD of about .0007 (seed_mc.py). The digits also depend on the run order (sorted by slot, then log name) and on the numpy version, which is printed.
