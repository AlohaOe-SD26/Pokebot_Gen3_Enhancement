### 3. (a) Runs and clusters model

- **Throughput** (`frames.py`, VERIFIED): completed runs average 4.573M frames (n = 65; median about 4.1M; SD about 1.95M). The 4-lane baseline ran at 799 and 722 fps per lane, giving .542 and .549 completed runs per lane-hour. At 700 fps that is .551 runs per lane-hour, which matches the ~0.55 you quoted.
- **Frame budget:** 13 h × 3600 × fps, which is 32.8M frames at 700, 29.0M at 620 and 26.2M at 560. I used your 620 and 560. A straight line between the 8-lane (700) and 32-lane (497) anchors gives 632 and 565; interpolating on log2 of the lane count gives 599 and 539. Moving 60 fps shifts δ80 by about .002–.003.
- **Runs:** each lane starts runs back to back until its budget is spent. The run that crosses the budget is in progress and keeps only battles that started before the cut, so there is exactly 1 in-progress run per lane.
- **Seed pool** (`collide.py`, VERIFIED): same-PID pairs within a batch occur at 27/299 = .0903 (across batches 21/332 = .0633). So each lane is modelled as drawing uniformly from its own pool of 11 seeds. On the baseline blocks this predicts 51.0 distinct PIDs against 53 observed, so it slightly overstates collisions, which is conservative.

### 4. (b) How the pseudo-arms were built

- **Population:** the 65 completed runs from both batches. The 8 in-progress runs are left out because they are censored, which slightly under-represents long runs.
- **Population clusters:** (species, PID), merged across lanes and batches: Torchic 14, Mudkip 10, Treecko 15.
- **Building a pseudo-arm:**
  - A new (species, seed) in a lane is assigned a population cluster of that species, drawn without replacement inside the lane and with replacement across lanes and arms.
  - A repeated seed takes the next unused run from that same population cluster; once those run out, it takes a random copy.
- **Analysis cluster:** (arm, species, lane, seed). Strata are arm × species, and the estimand follows your items 2–5 exactly.
- **Real-data check** (`baseline.py`, VERIFIED, 10,000 draws): batch0927 minus batch0926 gives Delta = −.022, 95% CI [−.085, +.031], bootstrap SD .0295, on 27 and 23 clusters. This is not a pure A/A test, because the builds changed between and within the batches.

"""READ-ONLY: per-RUN extraction for the step-14 power study (v2 estimand). Writes runs.json here.
Per run: batch, lane, log, in_progress (= the LAST log of its lane in its batch: the batch was parked mid-run),
starter species + PID (first '[hb] ... ids=['<Species>#<PID8>:' line), frames (last f-stamp),
key battles in log order (raw decomp name, label, group, outcome) by keybattles2's rules (unchanged),
non-key TRAINER battles: battle with NO "[STEP] 'Encountered" line inside it, outcome not wild-only, foe
(species, level) set non-empty and a subset of SOME decomp trainer party, and not classified key.
For each non-key trainer battle: lost (Lost/Draw) flag and whether an '[ITEM] using' line occurred inside it."""
import collections, json, os, re, sys
sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 's14power'))
import keybattles as k
import keybattles2 as k2

HERE = os.path.dirname(os.path.abspath(__file__))
ID_RE = re.compile(r"\[hb\] .*ids=\['([A-Za-z]+)#([0-9A-F]{8}):")
FRAME_RE = re.compile(r"^f(\d+) ")
ITEM_RE = re.compile(r"\[ITEM\] using")


def battles(path):
    cur_map, inb = None, False
    last_f, starter = 0, None
    out = []
    with open(path, encoding="utf-8", errors="replace") as fh:
        for line in fh:
            m = FRAME_RE.match(line)
            if m:
                last_f = int(m.group(1))
            if starter is None and "[hb]" in line:
                m = ID_RE.search(line)
                if m:
                    starter = (m.group(1), m.group(2))
            if "[MAP]" in line:
                m = k.MAPLINE_RE.search(line)
                if m:
                    cur_map = (m.group(1).strip(), int(m.group(2)), int(m.group(3)))
            elif "[hb]" in line:
                m = k.MAP_RE.search(line)
                if m:
                    cur_map = (m.group(1).strip(), int(m.group(2)), int(m.group(3)))
            if "[BATTLE] started" in line:
                inb, seen, bmap, items, enc, f0 = True, [], cur_map, 0, False, last_f
            elif inb and "[BATTLE] ended" in line:
                m = k.END_RE.search(line)
                out.append(dict(map=bmap, seen=tuple(dict.fromkeys(seen)), oc=m.group(1) if m else "?",
                                items=items, enc=enc, f=f0))
                inb = False
            elif inb:
                if "[STEP] 'Encountered " in line:
                    enc = True
                if "[TURN" in line:
                    m = k.TURN_RE.search(line)
                    if m:
                        seen.append((k.norm(m.group(1)), int(m.group(2))))
                if ITEM_RE.search(line):
                    items += 1
    return out, starter, last_f


def main():
    t = k.load_decomp()
    key = {n: v for n, v in t.items() if v[0] in k.KEY_CLASS_GROUP}
    nonkey = [v[1] for n, v in t.items() if v[0] not in k.KEY_CLASS_GROUP]
    allp = [v[1] for v in t.values()]
    res = []
    for batch in ("0926", "0927"):
        logs = k.select_logs(batch)
        last_of_lane = {}
        for lane, path in logs:
            last_of_lane[lane] = path  # select_logs is sorted by name within a lane
        for lane, path in logs:
            bl, starter, last_f = battles(path)
            keyb, ntr = [], []
            for b in bl:
                seen, oc = b["seen"], b["oc"]
                lost = oc in ("Lost", "Draw")
                hit = None
                if seen and not any(k.subset(seen, p) for p in nonkey):
                    for n, (cl, party, dbl) in key.items():
                        if not k.subset(seen, party):
                            continue
                        if n in k2.LEADER_ROOM:
                            if b["map"] and b["map"][1:] == k2.LEADER_ROOM[n]:
                                hit = n
                        elif cl in ("TRAINER_CLASS_LEADER", "TRAINER_CLASS_ELITE_FOUR", "TRAINER_CLASS_CHAMPION"):
                            continue
                        elif oc not in k2.WILD_ONLY and (len(set(seen)) >= 2 or len(party) == 1
                                                          or (lost and seen[0] in party[:2 if dbl else 1])):
                            hit = n
                        if hit:
                            break
                if hit:
                    keyb.append([hit, k2.label(hit), k.KEY_CLASS_GROUP[key[hit][0]], oc, b["items"], b["f"]])
                elif (not b["enc"]) and oc not in k2.WILD_ONLY and seen and any(k.subset(seen, p) for p in allp):
                    ntr.append([1 if lost else 0, 1 if b["items"] else 0, oc, b["f"]])
            res.append(dict(batch=batch, lane=lane[8:10], log=os.path.basename(path),
                            in_progress=(path == last_of_lane[lane]),
                            species=starter[0] if starter else None, pid=starter[1] if starter else None,
                            frames=last_f, key=keyb, ntr=ntr, n_battles=len(bl)))
    json.dump(res, open(os.path.join(HERE, "runs.json"), "w"))
    for batch in ("0926", "0927"):
        rs = [r for r in res if r["batch"] == batch]
        print(f"batch{batch}: {len(rs)} runs, in-progress {sum(r['in_progress'] for r in rs)}, "
              f"no starter {sum(r['species'] is None for r in rs)}, species {collections.Counter(r['species'] for r in rs)}")
        print("  key outcomes:", collections.Counter(b[3] for r in rs for b in r["key"]),
              " non-key trainer battles:", sum(len(r["ntr"]) for r in rs),
              " lost:", sum(x[0] for x in r["ntr"] for r in rs) if False else sum(x[0] for r in rs for x in r["ntr"]),
              " item battles:", sum(x[1] for r in rs for x in r["ntr"]))


if __name__ == "__main__":
    main()

"""READ-ONLY: within-lane starter-PID collision rate (the seed-pool model's one parameter).
Pairwise same-PID rate per lane: within-batch pairs, across-batch pairs. Uniform-pool fit: M = 1/rate.
Check: predicted vs observed distinct PIDs per (lane, batch) block. Cross-lane pairs (P2-P4 shared pool)."""
import json, itertools, collections, math
R = json.load(open('runs.json'))
lanes = ("P1", "P2", "P3", "P4")
tot_w = [0, 0]; tot_x = [0, 0]
rate = {}
for ln in lanes:
    rs = [r for r in R if r['lane'] == ln]
    w = [0, 0]; x = [0, 0]
    for a, b in itertools.combinations(rs, 2):
        same = a['pid'] == b['pid']
        if a['batch'] == b['batch']: w[0] += same; w[1] += 1
        else: x[0] += same; x[1] += 1
    tot_w[0] += w[0]; tot_w[1] += w[1]; tot_x[0] += x[0]; tot_x[1] += x[1]
    allp = (w[0] + x[0]) / (w[1] + x[1]); rate[ln] = allp
    print(f"{ln}: within-batch same-PID pairs {w[0]}/{w[1]} = {w[0]/w[1]:.3f}; across-batch {x[0]}/{x[1]} = {x[0]/x[1]:.3f}; "
          f"all {allp:.3f} -> uniform pool M = {1/allp:.1f}")
pw = tot_w[0] / tot_w[1]; px = tot_x[0] / tot_x[1]; pa = (tot_w[0] + tot_x[0]) / (tot_w[1] + tot_x[1])
print(f"POOLED: within-batch {tot_w[0]}/{tot_w[1]} = {pw:.4f}; across-batch {tot_x[0]}/{tot_x[1]} = {px:.4f}; all {pa:.4f} -> M = {1/pa:.2f}")
# observed vs predicted distinct per block under M = 1/pa
def ed(n, M): return M * (1 - (1 - 1 / M) ** n)
o = p = 0
for ln in lanes:
    for b in ("0926", "0927"):
        rs = [r for r in R if r['lane'] == ln and r['batch'] == b]
        d = len({r['pid'] for r in rs}); o += d; p += ed(len(rs), 1 / pa)
        print(f"   {ln} {b}: n {len(rs):2}  distinct {d}  predicted(M={1/pa:.1f}) {ed(len(rs), 1/pa):.2f}  predicted(lane M={1/rate[ln]:.1f}) {ed(len(rs), 1/rate[ln]):.2f}")

"""READ-ONLY sim engine for the step-14 v2 power study. Imported by the design scripts.

POPULATION = the 65 COMPLETED baseline runs (batch0926 + batch0927 pooled; the 8 in-progress runs are censored and
left out of the population). Population cluster = (species, starter PID), merged across lanes and batches (P2 and P4
share PIDs; a PID that recurs is a replay of the same seed).

SIMULATED LANE: frame budget F = 13 h x 3600 x fps. Runs are started back to back until the budget is spent; the run
that crosses the budget is IN PROGRESS and keeps only the battles that STARTED before the cut. Each run draws a seed
uniformly from the lane's own pool of M seeds (M = 1 / within-batch same-PID pair rate); a fixed lane's species is
fixed, a RANDOM lane's species is drawn uniformly from the three per run. A new (species, seed) in a lane is mapped to a
population cluster of that species, drawn uniformly, without replacement inside the lane while unused ones remain
(with replacement across lanes and arms); a repeated (species, seed) takes the next unused run of the same population
cluster, and once those run out, a random one of them (a copy = a replay).
ANALYSIS CLUSTER = (arm, species, lane, seed) [= (arm, species, PID) with lane-private pools]; strata = arm x species.
"""
import json, collections, os
import numpy as np

HERE = os.path.dirname(os.path.abspath(__file__))
SPECIES = ("Torchic", "Mudkip", "Treecko")
KSTAR = json.load(open(os.path.join(HERE, "kstar.json")))
_R = json.load(open(os.path.join(HERE, "runs.json")))
INF = float("inf")


class Pop:
    def __init__(self, runs):
        self.runs = []
        for r in runs:
            fK = np.full(len(KSTAR), INF)
            wK = np.zeros(len(KSTAR))
            for name, lab, grp, oc, items, f in r["key"]:
                if lab in KSTAR:
                    j = KSTAR.index(lab)
                    if fK[j] == INF:
                        fK[j] = f
                        wK[j] = 1.0 if oc == "Won" else 0.0
            nt = np.array([[x[3], x[0], 1.0 if (x[1] and not x[0]) else 0.0] for x in r["ntr"]], float).reshape(-1, 3)
            self.runs.append(dict(sp=r["species"], pid=r["pid"], frames=r["frames"], fK=fK, wK=wK,
                                  ntf=nt[:, 0], ntl=nt[:, 1], nti=nt[:, 2], log=r["log"]))
        self.clusters = collections.defaultdict(list)  # species -> list of lists of run idx
        tmp = collections.defaultdict(list)
        for i, r in enumerate(self.runs):
            tmp[(r["sp"], r["pid"])].append(i)
        for (sp, _p), idx in sorted(tmp.items()):
            self.clusters[sp].append(idx)

    def theta(self):
        """population theta: equal weight over species, then over K*; first-attempt win share among runs that fought X."""
        p = []
        for j in range(len(KSTAR)):
            ps = []
            for sp in SPECIES:
                n = sum(1 for r in self.runs if r["sp"] == sp and r["fK"][j] < INF)
                w = sum(r["wK"][j] for r in self.runs if r["sp"] == sp and r["fK"][j] < INF)
                if n:
                    ps.append(w / n)
            p.append(np.mean(ps))
        return float(np.mean(p)), p


POP = Pop([r for r in _R if not r["in_progress"]])


def sim_lane(rng, pop, sp_fixed, budget, M, state=None):
    """returns list of (pop_run_idx, cut_frame or None (= completed), (species, seed)).
    state = (seed_map, used) shared between lanes that share ONE seed pool (sensitivity arm only)."""
    out = []
    t = 0.0
    if state is None:
        state = ({}, collections.defaultdict(set))
    seed_map, used = state
    while t < budget:
        seed = int(rng.integers(M))
        sp = sp_fixed if sp_fixed else SPECIES[int(rng.integers(3))]
        key = (sp, seed)
        if key not in seed_map:
            cl = pop.clusters[sp]
            free = [c for c in range(len(cl)) if c not in used[sp]]
            c = free[int(rng.integers(len(free)))] if free else int(rng.integers(len(cl)))
            used[sp].add(c)
            q = list(cl[c])
            rng.shuffle(q)
            seed_map[key] = [cl[c], q]
        allruns, q = seed_map[key]
        i = q.pop() if q else allruns[int(rng.integers(len(allruns)))]
        fr = pop.runs[i]["frames"]
        if t + fr <= budget:
            out.append((i, None, key))
            t += fr
        else:
            out.append((i, budget - t, key))
            t = budget
    return out


def sim_arm(rng, pop, lanes, budget, M, arm_tag, shared_pool=False):
    """lanes: list of species or None (random). Returns list of (pop_idx, cut, clusterkey, species).
    shared_pool=True: all FIXED lanes of one species in an arm draw from ONE pool (the P2/P4 situation)."""
    res = []
    states = collections.defaultdict(lambda: ({}, collections.defaultdict(set)))
    for li, sp in enumerate(lanes):
        st = states[sp] if (shared_pool and sp) else None
        for i, cut, (s, seed) in sim_lane(rng, pop, sp, budget, M, st):
            lane_id = ("pool-" + str(sp)) if (shared_pool and sp) else li
            res.append((i, cut, (arm_tag, s, lane_id, seed), s))
    return res


def aggregate(pop, arm_runs, flip_pi=0.0, flip_f=0.0, rng=None, flipcache=None, flip_by_cluster=False):
    """Per species: cluster matrices. N, W (C x K) first attempts fought / won; RC (C x K) completed runs that fought X,
    CC (C,) completed runs; B5, L5 (C,) non-key trainer battles / lost(+Draw).
    flip_pi: first-attempt wins -> losses, keyed by (pop run, trainer) so every copy of a run flips alike;
    flip_f: WON item battles -> losses, keyed by (pop run, battle)."""
    K = len(KSTAR)
    per = {sp: collections.OrderedDict() for sp in SPECIES}
    for i, cut, ck, sp in arm_runs:
        r = pop.runs[i]
        lim = INF if cut is None else cut
        fought = (r["fK"] < lim).astype(float)
        w = r["wK"]
        if flip_pi > 0:
            fl = flipcache.setdefault(("K", ck if flip_by_cluster else None, i), rng.random(K) < flip_pi)
            w = np.where(fl, 0.0, w)
        m = r["ntf"] < lim
        lost = r["ntl"]
        if flip_f > 0:
            fl2 = flipcache.setdefault(("I", ck if flip_by_cluster else None, i), rng.random(len(r["ntl"])) < flip_f)
            lost = np.where(fl2 & (r["nti"] > 0), 1.0, lost)
        d = per[sp].setdefault(ck, [np.zeros(K), np.zeros(K), np.zeros(K), 0.0, 0.0, 0.0, 0])
        d[0] += fought
        d[1] += fought * w
        if cut is None:
            d[2] += (r["fK"] < INF)
            d[3] += 1
        d[4] += m.sum()
        d[5] += (lost * m).sum()
        d[6] += 1
    out = {}
    for sp in SPECIES:
        v = list(per[sp].values())
        if not v:
            out[sp] = None
            continue
        out[sp] = dict(N=np.array([x[0] for x in v]), W=np.array([x[1] for x in v]), RC=np.array([x[2] for x in v]),
                       CC=np.array([x[3] for x in v]), B5=np.array([x[4] for x in v]), L5=np.array([x[5] for x in v]),
                       NR=np.array([x[6] for x in v]))
    return out


def weights(rng, C, B):
    if B == 0:
        return np.ones((1, C))
    return rng.multinomial(C, np.full(C, 1.0 / C), size=B).astype(float)


def boot_stats(rng, aggA, aggB, B):
    """B == 0 -> point estimate (1 row). Else B bootstrap rows, clusters resampled within arm x species.
    Returns delta (theta_B - theta_A, equal weight over species with >=1 run that fought X in BOTH arms, then over X),
    thetaA, c5 (rate_B - rate_A, ratio of sums over the arm), c5A, reach (B - A, per X; completed runs only)."""
    K = len(KSTAR)
    nb = max(B, 1)
    pA, pB = {}, {}
    tot = {a: dict(L=np.zeros(nb), Bt=np.zeros(nb), RC=np.zeros((nb, K)), CC=np.zeros(nb)) for a in "AB"}
    for sp in SPECIES:
        for a, agg, store in (("A", aggA, pA), ("B", aggB, pB)):
            g = agg[sp]
            if g is None:
                store[sp] = (np.zeros((nb, K)), np.zeros((nb, K)))
                continue
            Wt = weights(rng, len(g["CC"]), B)
            store[sp] = (Wt @ g["N"], Wt @ g["W"])
            t = tot[a]
            t["L"] += Wt @ g["L5"]
            t["Bt"] += Wt @ g["B5"]
            t["RC"] += Wt @ g["RC"]
            t["CC"] += Wt @ g["CC"]
    num = np.zeros((nb, K))
    den = np.zeros((nb, K))
    thA = np.zeros((nb, K))
    for sp in SPECIES:
        nA, wA = pA[sp]
        nB, wB = pB[sp]
        ok = (nA > 0) & (nB > 0)
        sa = np.where(nA > 0, nA, 1.0)
        sb = np.where(nB > 0, nB, 1.0)
        num += np.where(ok, wB / sb - wA / sa, 0.0)
        thA += np.where(ok, wA / sa, 0.0)
        den += ok
    dd = np.where(den > 0, den, 1.0)
    dX = np.where(den > 0, num / dd, np.nan)
    tX = np.where(den > 0, thA / dd, np.nan)
    with np.errstate(invalid="ignore", divide="ignore"):
        delta = np.nanmean(dX, axis=1)
        thetaA = np.nanmean(tX, axis=1)
        c5A = tot["A"]["L"] / tot["A"]["Bt"]
        c5 = tot["B"]["L"] / tot["B"]["Bt"] - c5A
        rd = tot["B"]["RC"] / tot["B"]["CC"][:, None] - tot["A"]["RC"] / tot["A"]["CC"][:, None]
    return dict(delta=delta, thetaA=thetaA, c5=c5, c5A=c5A, reach=rd, nX=np.sum(den > 0, axis=1))


def design(nper):
    """nper fixed lanes of each species + nper random lanes, per arm"""
    return [sp for sp in SPECIES for _ in range(nper)] + [None] * nper

"""READ-ONLY: Monte Carlo of one design. Usage:
  run_design.py <nper> <fps> <S sims> <B boot> <seed> [pi=<flip prob K*>] [f=<item flip>] [M=<pool>] [shared]
nper = lanes per species per arm (fixed) + nper random lanes per arm. 13-h frame budget = 13*3600*fps.
Both pseudo-arms are drawn from the SAME population (sim.POP) => true Delta = 0 unless pi > 0 (planted in B).

C5 point diff + 90% CI lower, reach point diffs per K* trainer."""
import sys, json, time

import sim

args = sys.argv[1:]
nper, fps, S, B, seed = int(args[0]), float(args[1]), int(args[2]), int(args[3]), int(args[4])
opt = dict(a.split("=") for a in args[5:] if "=" in a)
pi = float(opt.get("pi", 0)); f = float(opt.get("f", 0)); M = int(opt.get("M", 11))
shared = "shared" in args[5:]
bycl = "bycluster" in args[5:]
tag = f"n{nper}_fps{int(fps)}_pi{pi:.4f}_f{f}_M{M}{'_shared' if shared else ''}{'_bycl' if bycl else ''}_s{seed}"

for s in range(S):
    A = sim.sim_arm(rng, sim.POP, lanes, budget, M, "A", shared)
    Bm = sim.sim_arm(rng, sim.POP, lanes, budget, M, "B", shared)
    cache = {}
    aA = sim.aggregate(sim.POP, A)
    aB = sim.aggregate(sim.POP, Bm, flip_pi=pi, flip_f=f, rng=rng, flipcache=cache, flip_by_cluster=bycl)
    pt = sim.boot_stats(rng, aA, aB, 0)
    bs = sim.boot_stats(rng, aA, aB, B)
    d = bs["delta"][~np.isnan(bs["delta"])]
    c5 = bs["c5"][~np.isnan(bs["c5"])]
    def cnt(arm):
        return dict(runs=len(arm), completed=sum(1 for x in arm if x[1] is None),
                    clusters=len({x[2] for x in arm}),
                    clusters_completed=len({x[2] for x in arm if x[1] is None}),
                    per_species_runs={sp: sum(1 for x in arm if x[3] == sp) for sp in sim.SPECIES})
    rows.append(dict(A=cnt(A), B=cnt(Bm), delta=float(pt["delta"][0]), thetaA=float(pt["thetaA"][0]),
                     nX=int(pt["nX"][0]), bsd=float(d.std()), lo=float(np.percentile(d, 2.5)),
                     hi=float(np.percentile(d, 97.5)), c5=float(pt["c5"][0]), c5A=float(pt["c5A"][0]),
                     c5lo90=float(np.percentile(c5, 5)), c5bsd=float(c5.std()),
                     reach=[float(x) for x in pt["reach"][0]]))
json.dump(dict(nper=nper, fps=fps, S=S, B=B, seed=seed, pi=pi, f=f, M=M, shared=shared, rows=rows),
          open(f"out_{tag}.json", "w"))
print(tag, "done", S, "sims in", round(time.time() - t0), "s")

"""READ-ONLY: power of the per-trainer REACH check (B - A), planted drop d, for one K* trainer.
Usage: reach_power.py <nper> <fps> <trainer index> <S> <B> <seed>
reach[a,X] = completed runs that fought X / completed runs (in-progress runs excluded), ratio of sums over the arm.
Planted: in arm B each COMPLETED run that fought X becomes a non-reacher with prob q = d / reach0(X), keyed by
(analysis cluster, pop run) => the expected reach drops by d. Cluster bootstrap within arm x species.
Flags: 'low95' = upper bound of the two-sided 95% CI < 0;  'low90' = upper bound of the 90% CI < 0."""
import sys, json, collections
import numpy as np
import sim

nper, fps, j, S, B, seed = int(sys.argv[1]), float(sys.argv[2]), int(sys.argv[3]), int(sys.argv[4]), int(sys.argv[5]), int(sys.argv[6])
budget = 13 * 3600 * fps
lanes = sim.design(nper)
P = sim.POP
reach0 = np.mean([r["fK"][j] < sim.INF for r in P.runs])  # population reach (completed runs)
rng = np.random.default_rng(seed)
GRID = [0.0, 0.02, 0.04, 0.06, 0.08, 0.10, 0.12, 0.14, 0.16, 0.20]


def per_cluster(arm_runs, q):
    g = collections.defaultdict(lambda: collections.OrderedDict())
    cache = {}
    for i, cut, ck, sp in arm_runs:
        if cut is not None:
            continue  # in progress: excluded from reach
        r = P.runs[i]
        fought = r["fK"][j] < sim.INF
        if fought and q > 0:
            if cache.setdefault((ck, i), rng.random() < q):
                fought = False
        d = g[sp].setdefault(ck, [0.0, 0.0])
        d[0] += fought
        d[1] += 1
    return {sp: np.array(list(v.values())) for sp, v in g.items()}


def boot(cl, Bn):
    num = np.zeros(Bn); den = np.zeros(Bn)
    for sp, a in cl.items():
        C = len(a)
        W = rng.multinomial(C, np.full(C, 1.0 / C), size=Bn).astype(float)
        num += W @ a[:, 0]; den += W @ a[:, 1]
    return num / den


res = {}
for d in GRID:
    q = min(d / reach0, 1.0)
    f95 = f90 = 0; diffs = []
    for _ in range(S):
        A = sim.sim_arm(rng, P, lanes, budget, 11, "A")
        Bm = sim.sim_arm(rng, P, lanes, budget, 11, "B")
        ca, cb = per_cluster(A, 0.0), per_cluster(Bm, q)
        pa = sum(v[:, 0].sum() for v in ca.values()) / sum(v[:, 1].sum() for v in ca.values())
        pb = sum(v[:, 0].sum() for v in cb.values()) / sum(v[:, 1].sum() for v in cb.values())
        diffs.append(pb - pa)
        bd = boot(cb, B) - boot(ca, B)
        f95 += np.percentile(bd, 97.5) < 0
        f90 += np.percentile(bd, 95) < 0
    res[d] = (f95 / S, f90 / S, float(np.mean(diffs)), float(np.std(diffs)))
name = sim.KSTAR[j]
print(f"{name} (reach0 {reach0:.3f}, lanes/arm {4*nper}, fps {fps:.0f}, S={S}, B={B}):")
for d, (a, b, m, s) in res.items():
    print(f"   planted d={d:.2f}: realized mean diff {m:+.4f} SD {s:.4f} | P(flag, 95% CI upper<0) {a:.3f} | P(flag, 90% CI upper<0) {b:.3f}")
json.dump({str(k): v for k, v in res.items()}, open(f"reach_{name}_n{nper}.json", "w"))
