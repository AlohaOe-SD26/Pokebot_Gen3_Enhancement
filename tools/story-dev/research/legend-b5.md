### Bot-Relevant Mechanics

This section addresses the specific questions for an autonomous bot.

**(a) Pokémon with Flee Behavior**

Only one static encounter has flee behavior. (VERIFIED)

*   **Latias / Latios (Roamer):** This is the classic roaming legendary. The battle script sets `B_FLAG_ROAMER` (`src/battle_setup.c`, `BattleSetup_StartRoamerBattle`), which enables fleeing on the first turn unless trapped by an ability (e.g., Arena Trap) or move (e.g., Mean Look). Its state (HP, status) is saved after each encounter. The bot must be prepared with a trapping strategy.

**(b) Un-catchable Encounters**

These are encounters where a battle is impossible or throwing a Poké Ball is disallowed.

1.  **Starter Selection:** The player chooses a starter from a bag. This is a gift, not a battle. (VERIFIED)
2.  **First Wild Battle (Route 101/103):** The battle against the wild Poochyena/Zigzagoon that attacks Professor Birch is scripted. You cannot lose this battle, and the `Poké Ball` command is disabled in the bag menu. This is a tutorial. (RECALL)
3.  **Rayquaza's Awakening (Sootopolis City):** The first time you interact with Rayquaza is during the Groudon/Kyogre conflict. You wake it at Sky Pillar, and it flies to Sootopolis. This is a cutscene event (`data/maps/SootopolisCity/scripts.inc`, `SootopolisCity_EventScript_WakeUpRayquaza`). There is no battle and no opportunity to catch it at this time. The catchable encounter is post-Elite Four at `MAP_SKY_PILLAR_TOP`. (VERIFIED)

**(c) Encounters That Are Permanently Lost Upon Defeat**

**This is the most critical list for a bot.** In Pokémon Emerald, defeating almost any one-time static encounter makes it disappear from the game forever. There is **no respawn mechanism** for these Pokémon upon re-beating the Elite Four, unlike in some later generations. The bot must prioritize capture over victory.

The following table lists every encounter that, if fainted, will be permanently unobtainable on the current save file, and the flag that records this state. A bot should **ALWAYS check if this flag is set** before attempting a hunt. If the flag is set, the hunt is impossible.
